Quality and size
Exported images. A phone photo is about 4000 px on its long side, so the default leaves them essentially untouched — resolution is the one thing worth spending file size on for a parser.
The PDF is for reading, so it does not need the full sensor. Lower this if the PDF is too heavy to attach.
JPEG at 92% is visually identical to the original on menu text and roughly a tenth the size of PNG. Turn on lossless only if the OCR run actually needs it.
